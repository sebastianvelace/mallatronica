# Contribuir a Mallatrónica

1. Abre un issue para describir errores o propuestas importantes.
2. Crea un fork y una rama para tu cambio.
3. Instala con `npm ci` y desarrolla con `npm run dev`.
4. Ejecuta `npm test`, `npm run build` y `git diff --check`.
5. Envía un pull request con el problema, la solución y las pruebas realizadas.

Mantén los cambios enfocados. Para modificaciones de UI, verifica teclado,
pantallas pequeñas, tema oscuro y preferencias de movimiento reducido.

Las reglas académicas necesitan una fuente oficial y fecha de consulta. No
conviertas un dato desconocido en una ausencia de requisitos. Distingue requisitos
confirmados, inferencias y restricciones pendientes de verificación.

No adjuntes datos personales, cookies, tokens, historias académicas ni capturas de
sesiones privadas. Usa datos sintéticos; `data/private/` está excluido de Git,
pero verifica siempre el diff antes de publicar.

Al aportar código original aceptas que se distribuya bajo la licencia MIT del
proyecto. Conserva las atribuciones y licencias de cualquier material de terceros.
